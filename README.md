# DASHBOARD de VENDAS -ANÁLISE de DADOS com EXCEL e IA
Este repositório contém o projeto final desenvolvido para o Bootcamp Santander. O objetivo principal foi criar uma base de dados comercial fictícia e transformá-la em um painel visual
(DASHBOARD) para tomada de decisões.
## O que foi desenvolvido:
## Base de Dados: ## Uma planilha com 15 registros de vendas contendo produtos, categorias, quantidades, preços unitários, e regiões.
## Fórmulas Aplicadas: ## Uso da fórmula matemática: =Quantidade * Preço Unitário, para o cálculo automático do faturamento total.
##Tabela Dinâmica:## Estruturação automatizada para agrupar e somar as vendas por tipo de produto 
## Visualização de Dados: ## Gráficos de colunas agrupadas demonstrando visualmente o faturamento de cada item.

## TECNOLOGIAS UTILIZADAS:
- MICROSOFT EXCEL ONLINE
- GITHUB ( para hospedagem e portfólio )
- INTELIGÊNCIA ARTIFICIAL ( para auxílio na tomada de decisão e estruturacão do projeto )
